# anime.js とは

**ウェブページの「動き」をつくることだけに特化した、JavaScript のライブラリです。**

「どの部品を・どこまで・何秒かけて・どんな加減速で動かすか」を書くと、
その通りに画面が動きます。動きを 1 コマずつ自分で計算する必要はありません。

公式サイト <https://animejs.com/>

---

# まず見てみる — `00-introduction.html`

`codes/00-introduction.html` をブラウザで開いてください。
同じ青い四角が 2 つ並んでいて、**右側だけが左右に動きます**。

違いは「anime.js を 1 つ足したかどうか」だけです。

## 左：HTML + CSS だけ

```html
<div class="box"></div>

<style>
  .box {
    width: 80px;
    height: 80px;
    background: #4f46e5;
    border-radius: 12px;
  }
</style>
```

HTML で「四角を置く」、CSS で「大きさと色を決める」。
これだけだと、四角はそこに**止まったまま**です。

## 右：そこに anime.js を足す

```html
<div class="box"></div>

<style>
  .box {
    width: 80px;
    height: 80px;
    background: #4f46e5;
    border-radius: 12px;
  }
</style>

<script type="module">
  import { animate } from 'animejs';

  animate('.box', {
    translateX: 250,
    loop: true,
    alternate: true,
  });
</script>
```

HTML と CSS はまったく同じ。下に `<script>` が増えただけです。
増えた 5 行はそれぞれこういう意味です。

| 書いたこと | 意味 |
| --- | --- |
| `animate('.box', {...})` | `.box` という部品を動かす |
| `translateX: 250` | 横方向に 250px の位置まで動かす |
| `loop: true` | 動き終わったらまた繰り返す |
| `alternate: true` | 繰り返すとき、行って・戻ってを交互にする |

**anime.js を使うというのは、要するにこれだけのことです。**
「動かしたいもの」と「どうなってほしいか」を書けば、間の動きは全部やってくれます。

このハンズオンで作る魔法陣も、やっていることは同じです。
四角が 1 つだったところが、魔法陣の線に変わるだけです。

# 補足 1：なぜライブラリを使うのか

パラパラ漫画と同じで、画面の動きは **1 秒間に約 60 枚の絵を差し替える**ことで作られています。

anime.js を使わずに同じ動きを作ろうとすると、自分でこう書くことになります。

- 1/60 秒ごとに呼び出される処理を用意する（`requestAnimationFrame`）
- 「開始から何ミリ秒経ったか」を毎回数える
- 経過時間から「今どの位置にいるべきか」を計算する
- 加減速をつけるための計算式（イージング）を自分で書く
- 目的の位置に着いたら止める

anime.js は、この**面倒な部分をまるごと肩代わり**してくれます。
書く側は「250px まで動かして」とだけ言えば済みます。

> どれくらい差が出るのかは、`01-without-animejs.html`（ライブラリなし）と
> `02-with-animejs.html`（anime.js あり）を見比べると分かります。
> まったく同じ動きですが、コードの量がはっきり違います。
> この比較は `D_anime-js×Three-js.md` で扱います。

# 補足 2：よく使う設定

`animate()` の `{ }` の中に書ける設定のうち、よく使うものです。

| 設定 | 意味 | 変えるとどうなるか |
| --- | --- | --- |
| `duration` | 動きにかける時間（ミリ秒） | `1000` なら 1 秒かけて動く。小さくすると速くなる |
| `delay` | 動き出すまでの待ち時間（ミリ秒） | 複数の部品の動き出しをずらせる |
| `ease` | 加減速のつけかた | `'linear'` は一定速度、`'outQuad'` は最後にゆっくり止まる |
| `loop` | 繰り返すかどうか | `true` で永久に繰り返す。`3` のように回数も書ける |
| `alternate` | 往復させるかどうか | `true` で「行き → 帰り」を交互に繰り返す |

動かす対象（`translateX` の部分）には、位置のほかに
`rotate`（回転）・`scale`（拡大縮小）・`opacity`（透明度）などが書けます。

このハンズオンの魔法陣では `rotate`（回す）を使っています。

# 補足 3：ハンズオンで出てくる道具

魔法陣のコードには、`animate()` 以外に 2 つの道具が出てきます。
名前だけ頭の片隅に置いておいてください。詳しくは `E_ハンズオンの説明.md` で扱います。

## `stagger` … 動き出しを少しずつずらす

```js
delay: stagger(60),
```

たくさんの部品を動かすとき、`60` ミリ秒ずつ順番に遅らせて動かします。
全部いっせいに動くより、順に波及していくように見えます。

## `svg.createDrawable` … 線を「描いている途中」にする

```js
draw: ['0 0', '0 1'],
```

図形の線を「長さ 0%」から「長さ 100%」まで伸ばします。
魔法陣がペンで描かれていくように見えるのは、この仕組みです。

# 補足 4：使いはじめるのに必要なもの

**インストール作業はありません。** HTML に次の 1 行を書くだけです。

```html
<script type="module">
  import { animate } from 'https://cdn.jsdelivr.net/npm/animejs@4.5/+esm';
</script>
```

インターネット上に置かれた anime.js を、ブラウザが直接読みに行きます。
`@4.5` の部分がバージョン指定です。

# 補足 5：バージョンの話（検索するときの注意）

anime.js は **v4 で書き方が大きく変わりました。**

| | 書き方 |
| --- | --- |
| 旧（v3 まで） | `anime({ targets: '.box', translateX: 250 })` |
| 現行（v4 以降） | `animate('.box', { translateX: 250 })` |

ネットで検索すると **古い書き方の記事が多く出てきます。**
そのまま貼り付けても動かないことがあるので、
うまくいかないときは公式ドキュメントを確認するのが確実です。

また、このハンズオンで使う **three.js 対応（adapter）は v4.5 から**の機能です。

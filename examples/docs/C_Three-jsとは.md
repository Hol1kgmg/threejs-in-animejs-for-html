# three.js とは

**ウェブページの中に「立体（3D）」を表示するための、JavaScript のライブラリです。**

HTML と CSS でできるのは、基本的に**平らな画面**の表現です。
そこに「奥行き」を持ち込んで、立体を置いたり、視点を動かしたりできるようにするのが three.js です。

公式サイト <https://threejs.org/>

---

## 何ができるのか

ブラウザだけで、こういうものが作れます。

- 立方体や球などの立体を置いて、くるくる回す
- 商品や建物の 3D モデルを、マウスでぐるっと見回せるようにする
- 光を当てて、影や質感をつける
- カメラを動かして、空間の中を移動する

インストールは不要で、**ブラウザで HTML を開くだけ**で動きます。

## 3 つの部品でできている

three.js は、写真を撮るときと同じ考え方をします。

| 部品 | 役割 | たとえると |
| --- | --- | --- |
| シーン（Scene） | 立体を置いておく空間 | 撮影スタジオ |
| カメラ（Camera） | どこから、どの向きで見るか | カメラ |
| レンダラー（Renderer） | それを画面に描き出す係 | 現像・プリント |

**「空間を用意して、ものを置いて、カメラから見た姿を画面に描く」**
——これが three.js の基本の流れです。

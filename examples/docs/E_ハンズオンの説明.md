# ハンズオンの進め方

ここからは資料ではなく、**実際にコードを触る時間**です。
先に「どこから始めて、何をするのか」だけ揃えてから始めます。

---

# いまからやること

**`04-magic-circle-handson.html` を開いて、`main()` の中のコメントを 4 回外す。それだけです。**

| | 画面の状態 |
| --- | --- |
| **ビフォー**（いまの `04`） | 検索フォームが 1 つあるだけ |
| **アフター**（STEP 4 まで終えたあと） | 魔法陣が 3 層に分かれて順番に描かれ、描き終わった層から回りはじめる |

新しくコードを書き起こす作業はありません。
**すでに書いてあるものを、順番に有効にしていく**という進め方です。

---

# スタート地点 — `04-magic-circle-handson.html`

## 1. まずブラウザで開く

`codes/04-magic-circle-handson.html` をブラウザで開いてください。
**検索フォームだけが表示されます。**

魔法陣は「まだ書かれていない」のではありません。

- 魔法陣の図形（SVG）… **最初から書いてあります**（ファイル末尾の `SIGIL ARTWORK`）
- 見た目の CSS … **最初から書いてあります**（`★ THEME`）
- それを動かす JS の呼び出し … **すべてコメントアウトしてあります**

つまり、**部品は全部そろっているのに、動かす命令だけ止めてある**状態です。
その命令を 1 行ずつ復活させていくのが、このハンズオンです。

## 2. 次に VSCode で開く

同じファイルを VSCode でも開いてください。ブラウザと VSCode を**両方開いたまま**進めます。

書き換えるのは `main()` という関数の中**だけ**です。それ以外は一切触りません。

ファイルの中は、目印コメントで場所が分けてあります。

| 目印 | どこ | 役割 |
| --- | --- | --- |
| `★ THEME` / `★ FORM THEME` | CSS の先頭 | 色や大きさ。**時間が余ったら触る** |
| `★ CONTROL PANEL` → `SETTINGS` | JS の前半 | 速度・順番・タイミングの数値。**時間が余ったら触る** |
| `★ CONTROL PANEL` → `SEQUENCE` | JS の中ほど | **← ここの `main()` の中だけを触ります** |
| `ENGINE` | JS の後半 | 実際の描画・回転の処理。触らない |
| `SIGIL ARTWORK` | HTML の末尾 | 魔法陣の図形データ。触らない |

`★` が付いていないところは、読み飛ばして構いません。

---

# おおまかな流れ

魔法陣が出てくるまでの段取りは、**「集める → 準備する → 描く → 回す」**の一本道です。

```
  [STEP 1]        [STEP 2]         [STEP 3]        [STEP 4]
   集める    →     準備する    →     描く      →     回す

  SVG を                線の長さを      0% → 100% に    描き終わった層
  拾ってきて            0 にしておく    伸ばす          から回転開始
  画面に出す

  ↓ 画面          ↓ 画面           ↓ 画面          ↓ 画面
  止まった        いったん          3 層が順に      完成
  魔法陣が出る    消える            描かれる
```

STEP ごとの内訳はこうなります。

| | STEP | やること | 画面がどう変わるか | 目安 |
| --- | --- | --- | --- | --- |
| 1 | 魔法陣を表示する | `showLayers(collectLayers());` のコメントを外す | 止まった魔法陣が出る | 5 分 |
| 2 | 描画の準備をする | STEP 1 の行を戻し、`prepareLayers(...)` に差し替える | 魔法陣が消える | 3 分 |
| 3 | 線を描く | `let startAt` からのかたまりのコメントを外す | 3 層が順番に描かれる | 6 分 |
| 4 | 描き終わった層から回す | `startDrawing(...)` に `.then(...)` を足す | 完成 | 6 分 |

各 STEP のコメントの外し方は、**ファイルの中のコメントに全部書いてあります。**
この資料に戻ってこなくても、`04` を上から読んでいけば進められます。

## STEP 2 で「消える」のは正常です

いちばん驚かれるのが STEP 2 です。STEP 1 で出た魔法陣が、**いったん何も見えなくなります。**

これは失敗ではありません。
`prepareLayers` が「これから描くために、全部の線の長さを 0 にしておく」処理だからです。
図形は画面の上にちゃんと置かれていて、**長さが 0 なので見えていないだけ**です。

ここで長さを 0 にしておかないと、STEP 3 で描き始める前に完成形が一瞬チラッと見えてしまいます。

# 進め方のルール

1. **1 STEP ごとに保存して、ブラウザを再読み込みする。**
   まとめて 4 つ外さないでください。どの行が何を起こしたのかが分からなくなります。
2. **変化を目で確認してから次へ進む。**
   表の「画面がどう変わるか」と同じになっていれば正解です。
3. **詰まったら `98-magic-circle-search.html` を開く。**
   STEP 4 まで終えた完成形です。答え合わせをしたら、そこから先へ進んでください。
   全員で足並みを揃えるより、最後まで見てもらうことを優先します。

## うまくいかないときに見るところ

| 症状 | よくある原因 |
| --- | --- |
| 何も変わらない | ファイルを**保存していない** / ブラウザを再読み込みしていない |
| 変化しない・エラーが出る | 行頭の `// ` の消し忘れ（複数行のかたまりは**全部**外す） |
| STEP 2 で消えたまま | **正常です。** STEP 3 に進んでください |
| 真っ白になる | 括弧 `{ }` `( )` を消しすぎ。`98` と見比べてください |

> ブラウザの開発者ツール（F12）の Console にエラーが出ていれば、そこに原因が書かれています。
> 分からなければ遠慮なく呼んでください。

# 早く終わった方へ

STEP 4 まで終わったら、次のどれでも触ってみてください。**壊しても元に戻せます**（`98` が完成形の控えです）。

## 1. 数値を変える — `★ SETTINGS`

`LAYERS` の中の数値を書き換えると、動き方が変わります。

| 変えるもの | 試してみると |
| --- | --- |
| `order` | 描かれる順番が変わる（`0` が最初）。外側から描いてみる |
| `drawDuration` | 描き切るまでの時間。小さくすると一気に描かれる |
| `drawStagger` | 線 1 本ずつのズレ。`0` にすると全部同時に描かれる |
| `spinDuration` | 1 回転の時間。小さくすると目が回ります |
| `spinDirection` | `1` と `-1` で回転方向が逆になる |

## 2. 色を変える — `★ THEME`

`--sigil-ink`（線の色）と `--form-accent-rgb`（フォームの水色）を書き換えると、
配色が一括で変わります。パーツ単位で変えたいときは `--ink-l1-ticks` などを直接指定します。

設定する色のコードを探したい場合はこちらのサイトが参考になります

[WEB色見本 - 原色大辞典](https://www.colordic.org/)

## 3. ゼロから書いてみる — `03-animejs-playground.html`

`03-animejs-playground.html` は、**白 × 紺の検索フォームだけが置かれた、まっさらなファイル**です。
JavaScript は空っぽなので、`B_anime-jsとは.md` を見ながら自分で `animate()` を書いて試せます。

```html
<script type="module">
  import { animate } from 'https://cdn.jsdelivr.net/npm/animejs@4.5/+esm';

  // 例：検索ボタンを揺らしてみる
  animate('button', {
    translateY: -10,
    loop: true,
    alternate: true,
  });
</script>
</body>
```

`</body>` の直前にこれを貼って、ブラウザで開き直してみてください。

# つくったものを、実際に使う

このページの検索フォームは**飾りではありません。**
入力して「検索」を押すと、**本当に Google の検索結果が開きます。**

```html
<form action="https://www.google.com/search" method="GET">
  <input type="text" name="q" placeholder="Google検索" autofocus>
```

`action` が「送り先 = Google の検索ページ」、`name="q"` が「入力内容を検索語として渡す」という指定です。
つまり、このファイルを**ブラウザの起動時ページに設定すれば、そのまま自分の検索ページとして使えます。**

## 設定のしかた

### 1. ファイルのパスを調べる

VSCode の左のファイル一覧で `98-magic-circle-search.html` を**右クリック → 「パスのコピー」**（Copy Path）。

一度ブラウザで開いてから、**アドレスバーの `file:///...` をコピー**しても同じです。

### 2. 起動時に開くページに設定する

| ブラウザ | 手順 |
| --- | --- |
| **Google Chrome** | アドレスバーに `chrome://settings/onStartup` → 「特定のページまたはページセットを開く」→「新しいページを追加」→ コピーしたパスを貼り付け |
| **Microsoft Edge** | アドレスバーに `edge://settings/onStartup` → 「これらのページを開く」→「新しいページを追加」→ 同上 |

貼り付けるときは、頭に `file:///` が付いた形にしてください（例: `file:///Users/name/examples/codes/98-magic-circle-search.html`）。
Windows なら `file:///C:/Users/name/...` のようになります。

これで**ブラウザを起動するたびに魔法陣が描かれ**、そのまま検索できます。

### 3. ホームボタンにも設定しておくと便利

起動時だけでなく、いつでも呼び出したい場合はホームボタンにも登録します。

- Chrome: `chrome://settings/appearance` →「ホームボタンを表示する」をオンにして、同じパスを入力
- Edge: `edge://settings/appearance` →「ホームボタン」をオンにして、同じパスを入力

ツールバーの 🏠 を押せば、いつでもこのページに戻れます。

## 使うファイルの選び方

| ファイル | どんな検索ページになるか |
| --- | --- |
| `98-magic-circle-search.html` | 黒 × 水色。魔法陣が描かれて回る（**おすすめ**） |
| `99-magic-circle-3d.html` | 3 層が奥行き方向に並んだ立体版 |
| `03-animejs-playground.html` | 白 × 紺のシンプル版。動きなし |
| `04-magic-circle-handson.html` | 自分で STEP 4 まで仕上げたもの |

**自分で数値や色を書き換えたファイルをそのまま指定できます。**
`★ SETTINGS` の回転速度や `★ THEME` の色を好みに変えたものを、自分の検索ページにしてください。

## 注意点

- **ファイルを移動・削除すると開けなくなります。** 消さない場所（書類フォルダなど）に置いてから設定してください。
- **「新しいタブ」のページは、この方法では変更できません。**（ブラウザの仕様上、拡張機能が必要です）
  変わるのは「起動時に開くページ」と「ホームボタン」の 2 つです。
- ローカルのファイルなので、**インターネットに接続していない状態でも魔法陣は表示されます**（検索そのものには接続が必要です）。

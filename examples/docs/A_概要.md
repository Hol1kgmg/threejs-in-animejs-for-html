# 概要

## このハンズオンでつくるもの

**「ただの検索フォーム」を、魔法陣が描かれて回りだす画面に作り替えます。**

最初は入力欄とボタンがあるだけのシンプルなページです。
そこにコードを 4 ステップ足していくと、

1. 魔法陣が画面に現れ
2. いったん線が消え
3. 外側・中間・中心の 3 層が順番に描かれ
4. 描き終わった層から回りはじめる

という一連のアニメーションが動きます。
最後の +α では、その魔法陣を**そのまま 3D 空間に持ち上げて**、立体的に重なった魔法陣にします。

## 対象と前提

- **プログラミングに詳しくない方**を想定しています。数式や 3D の知識は要りません。
- 用意するのは **VSCode** と **WEB ブラウザ**（Google Chrome / Edge など）だけです。
- 環境構築・インストール作業はありません。HTML ファイルをブラウザで開くだけで動きます。
- 触る言語は **HTML / CSS / JavaScript** です。

## このハンズオンのねらい

### 1. 「アニメーションを自分で書く大変さ」を知る

まったく同じ動きを、

- `01-without-animejs.html` … 素の JavaScript（`requestAnimationFrame` と手書きのイージング）
- `02-with-animejs.html` … anime.js

の 2 通りで見比べます。
**ライブラリが何を肩代わりしてくれているのか**が、コードの量の差としてはっきり見えます。

### 2. anime.js の書き方を、手を動かして覚える

anime.js は「**何を・どこまで・何秒かけて・どんな加減速で**動かすか」を書くだけでアニメーションが作れるライブラリです。
ハンズオンでは、すでに用意された魔法陣に対してその記述を 1 ステップずつ足していきます。
コードを書き換える場所は **CONTROL PANEL と書かれたブロックの中だけ**に絞ってあるので、全体を理解していなくても進められます。

### 3. anime.js v4.5 の three.js adapter を体験する

anime.js は v4.5 で **three.js（3D 表現のライブラリ）に対応**しました。
アダプターを読み込むと、3D のオブジェクトを **HTML 要素を動かすときとまったく同じ書き方**で動かせるようになります。

そのため、2D でつくった魔法陣のコードは**ほとんど書き換えずに 3D 版へ流用できます**。
`98`（2D）と `99`（3D）の 2 ファイルを見比べて、**何が同じで、何が増えたのか**を確認するのがこのハンズオンの締めくくりです。

# codes/docsのファイル説明

## codes/ — 使用するコード

| ファイル | 内容 |
| --- | --- |
| `00-introduction.html` | anime.js の最小限のコード例。四角形が 1 つ動くだけの、いちばん短いサンプル |
| `01-without-animejs.html` | three.js のアニメーションを**素の JavaScript だけ**で実装した場合。`requestAnimationFrame` と手書きのイージングが必要になる |
| `02-with-animejs.html` | `01` とまったく同じ動きを **anime.js の three.js adapter** で書いた場合。`animate(mesh, {...})` だけで済む |
| `03-animejs-playground.html` | 白 × 紺の検索フォームだけが置かれた**まっさらなファイル**。JavaScript は空。自分でゼロから書いて試すための場所 |
| `04-magic-circle-handson.html` | 魔法陣の図形（SVG）と CSS は書いてあるが、それを動かす JS がすべてコメントアウトされている。`main()` の中の STEP 1 → 4 を順にコメント解除していく |
| `98-magic-circle-search.html` | `04` の**完成形（2D 版）**。黒 × 水色の検索フォームに魔法陣が重なる |
| `99-magic-circle-3d.html` | `98` を **3D 空間に置いた版**。CSS3DRenderer で 3 層を奥行き方向に並べ、空間ごと傾けている |

### 触る場所・触らない場所

`04` `98` `99` の 3 ファイルは、コード中に目印コメントを入れてあります。

- `★ THEME` / `★ FORM THEME`（CSS の先頭）… **色や大きさ**を変える場所
- `★ CONTROL PANEL`（JS の先頭）… **速度・順番・タイミング**を変える場所
  - `SETTINGS` … 数値や色などの設定値
  - `SEQUENCE` … どの順番で何を実行するかの流れ
- `SIGIL ARTWORK`（HTML の末尾）… 魔法陣の図形そのもの。**触らなくてよい場所**

`★` が付いたブロックだけ触れば見た目と動きは一通り変えられます。
